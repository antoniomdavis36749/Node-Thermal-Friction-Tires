```bbcode
[B]Tire Wear and Thermals ReSpin — Compat Tires[/B]
Extra tire parts and ready-to-drive Scintilla setups. This is [B]not[/B] the heat/wear mod — install [B]core ReSpin[/B] first: [URL]https://www.beamng.com/resources/tire-wear-and-thermals-respin.39082/[/URL]

[HR][/HR]
[B]Requires[/B] the core heat/wear/apps mod: [URL]https://www.beamng.com/resources/tire-wear-and-thermals-respin.39082/[/URL]

[HR][/HR]
[B]What you get[/B]
• Extra street tires for stock wheels: Sport Plus, Track Day, Hard, and Medium. Stock Sport / Race / Standard stay in the list.
• Scintilla GT3 Respin slicks: Hard, Medium, Soft, and Supersoft
• Ready-to-drive Scintilla configs: [B]GT3 ReSpin Endurance[/B] (Hard / Medium / Soft) and [B]Qualify Supersoft[/B]
• Pigniteon ETKC Grip-All GT3 Respin tires
• Same 3D models as stock / the car pack — only the tire files are new

[HR][/HR]
[B]How to use[/B]
1. Install [B]Tire Wear and Thermals ReSpin[/B] (core — heat, wear, and the apps): [URL]https://www.beamng.com/resources/tire-wear-and-thermals-respin.39082/[/URL]
2. Install [B]this[/B] Compat Tires pack.
3. For GT3: also install [I]Scintilla GT3 Racing Parts[/I] and/or [I]Pigniteon ETK Racing[/I] (for the 3D models).
4. On Scintilla, pick a [B]GT3 ReSpin[/B] config from the vehicle list (Endurance Hard / Medium / Soft, or Qualify Supersoft). On other cars: Parts → tires → pick a name ending in [B]Respin[/B].

[HR][/HR]
[B]Why a second download?[/B]
If these tires lived inside the core zip, BeamNG would hide the apps. Keep this pack separate.
```
