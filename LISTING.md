Optional selectable [B]NTF[/B] tire parts and Scintilla GT3 race configs for [B]Node-Thermal Friction[/B].

• Scintilla GT3 NTF configs (Baseline + Endurance only — mirrors GT3 pack)

Pressure wheels use [B]numRays 16[/B]. Higher counts can break modded vehicles.

1. Enable core Node-Thermal Friction.
2. Enable this Compat pack.
3. Parts → tires → NTF, or load a GT3 NTF Scintilla config.
4. Add Classic or Crew from core.
